# Serveur #2 - Fichiers de Test

Ce répertoire appartient au **second serveur virtuel** de Webserv.

## Configuration
- **Port :** 8081
- **Server name :** example.com
- **Autoindex :** ON
- **Méthodes :** GET, POST, DELETE

## Test d'Autoindex
Accédez à `http://localhost:8081/` pour voir la liste des fichiers avec l'autoindex activé.

## Différences avec le serveur principal
Le serveur principal (port 8080) a l'autoindex désactivé, tandis que ce serveur l'a activé pour démontrer la fonctionnalité.
